I like software that disappears into the workflow: press a key, say a thing, it's done. Most of what I ship is Windows desktop work in C#/.NET and scripts for the FiveM ecosystem.

<br>

## Featured

<table>
  <tr>
    <td width="50%" valign="top">
      <h3><a href="https://github.com/lenox3/Bvoice">Bvoice</a></h3>
      <p>Local, private AI voice typing for Windows. Hold a key, speak naturally, pause to think, release, and clean text lands wherever your cursor is.</p>
      <ul>
        <li>whisper.cpp on Vulkan / CUDA / CPU, nothing uploaded</li>
        <li>Pause-aware streaming so thinking pauses are not endings</li>
        <li>Self-corrections, fillers, voice commands, per-app profiles, phonetic vocabulary</li>
        <li>WPF + WebView2, tray, overlay, installer, real-speech test suite</li>
      </ul>
      <p><code>C#</code> <code>.NET 8</code> <code>WPF</code> <code>whisper.cpp</code> <code>ONNX</code></p>
    </td>
    <td width="50%" valign="top">
      <h3><a href="https://github.com/lenox3/qb-notify">qb-notify</a></h3>
      <p>Notification system for the QBCore framework on FiveM. Replaces the default <code>QBCore.Functions.Notify</code> through a single export.</p>
      <ul>
        <li>Success, error, primary and warning styles with configurable duration</li>
        <li>Responsive UI built with Tailwind CSS</li>
